# Exceller Accounting

Exceller is a self-contained accounting system for small businesses: invoices, bills, quotes, purchase orders, bank reconciliation, VAT, inventory, fixed assets, projects and time tracking, budgets and reports.

## Stand-alone version

`Exceller_accounting_system.html` is the whole app in a single file. No installation is needed.

1. Download `Exceller_accounting_system.html`.
2. Open it in a modern web browser (Chrome, Edge, Firefox or Safari).
3. It starts with demo data for a fictional company ("Apex Trading"), so you can try things out. When you're ready, go to **Setup** to start your own books or import your data.

Your data is saved in your browser on your own computer; nothing is sent anywhere unless you turn on an online backup (Google Drive or OneDrive). Make regular backups from the **Setup** page, since clearing your browser's data also clears your books.

Note: the stand-alone file can't receive bank feed webhooks. Those need the Exceller server running over HTTPS.
